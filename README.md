# CyberLooter

Мод доступности для Cyberpunk 2077: короткое удержание одной клавиши собирает весь лут
в радиусе вокруг персонажа. Сделан для игры без необходимости наводиться на каждый труп,
ящик и предмет по отдельности.

**Зависимость ровно одна — [Cyber Engine Tweaks](https://github.com/maximegmd/CyberEngineTweaks).**
Ни redscript, ни RED4ext, ни ArchiveXL, ни прочей обвязки не требуется.

## Установка

1. Установить Cyber Engine Tweaks (актуальная версия v1.37.1).
2. Скопировать папку `CyberLooter` в
   `Cyberpunk 2077\bin\x64\plugins\cyber_engine_tweaks\mods\`.
3. Запустить игру, открыть оверлей CET (по умолчанию `~`).
4. Вкладка **Bindings** → секция **CyberLooter** → назначить клавишу на
   «CyberLooter: loot everything around». Обычно это та же клавиша, что и взаимодействие
   (по умолчанию `F`).

Пока клавиша не назначена, мод ничего не делает и честно сообщает об этом в своём окне.

## Как пользоваться

Коротко зажать назначенную клавишу. Как только удержание дошло до порога (по умолчанию
0.35 секунды), весь лут в радиусе уезжает в инвентарь — клавишу можно сразу отпускать,
держать дальше не нужно.

Когда рядом есть что подобрать, появляется обычная игровая подсказка кнопки с количеством
позиций: `Собрать всё · 7`. Нет лута — подсказки нет.

Если ты смотришь на объект и игра показывает свою подсказку взаимодействия, мод молчит:
клавиша в этот момент работает по-ванильному. Отведи взгляд — и автосбор снова доступен.

## Настройки

Окно настроек открывается вместе с оверлеем CET.

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Radius | 5 м | Радиус сбора |
| Hold time | 0.35 с | Порог удержания |
| Max objects per sweep | 24 | Предел объектов за одно срабатывание |
| Skip quest loot | вкл | Не трогать квестовые предметы |
| Ignore key while a vanilla prompt is up | вкл | Не вмешиваться в ванильные взаимодействия |
| Show indicator | вкл | Показывать подсказку кнопки |
| Use game key icon | вкл | Брать иконку клавиши у игрового действия взаимодействия |
| Re-send hint instead of updating | выкл | Обходной путь, если подсказки начнут дублироваться |
| ImGui fallback indicator | выкл | Запасной индикатор, если движковый не заработает |
| Write cyberlooter.log | выкл | Подробный диагностический лог |

Настройки сохраняются в `config.json` при закрытии оверлея.

Текст подсказки задаётся полем `hintLabel` в `config.json`. По умолчанию он на русском;
если игра запущена на другом языке и вместо букв видны квадраты, поменяй на латиницу
(например, `Loot All`).

## Диагностика

Если что-то работает не так: включить **Write cyberlooter.log**, поиграть пару минут,
прислать файл `cyberlooter.log` из папки мода. В нём видно, какая стратегия поиска лута
сработала, сколько объектов найдено, что удалось забрать и где именно случился отказ.

## Как это устроено

Мод не изобретает свою механику подбора, а вызывает ту же функцию, что и сама игра при
нажатии F на трупе — `TransactionSystem.TransferAllItems`. Индикатор тоже не рисуется
вручную: используется штатная система подсказок кнопок движка, поэтому он выглядит и
анимируется как родной.

Подробности с ссылками на код игры — в [docs/RESEARCH.md](docs/RESEARCH.md),
архитектура — в [docs/PLAN.md](docs/PLAN.md).
